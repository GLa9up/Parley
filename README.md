# PARLEY — ล่ามพกพา

แอปแปลบทสนทนาสองทางแบบเรียลไทม์ หน้าจอเดียว ถือโดยเจ้าของเครื่องคนเดียว
ตั้งสองภาษาที่จะคุยไว้ครั้งเดียว แล้วแตะไมค์พูดสลับกันไปมาได้เลย
ไม่ต้องเลือกว่าใครพูดก่อน — แอปสลับภาษาที่คาดว่าจะฟังให้อัตโนมัติทุกครั้งที่แปลเสร็จ

- ไฟล์เดียวจบ ไม่ต้อง build ไม่ต้องติดตั้งอะไร
- รองรับ 36 ภาษา ตั้งคู่ภาษาแล้วสลับตำแหน่งได้ด้วยปุ่ม ⇄
- แตะไมค์แล้วพูดได้เลย ไม่ต้องกดเลือกฝั่งก่อนพูด — แอปฟังสองภาษาพร้อมกันแล้วเดาให้เอง
- มีปุ่ม ↺ ล้างบทสนทนาทั้งหมด
- ถ้าไมค์ใช้ไม่ได้ (เช่นบน iPhone/Safari) กดปุ่ม ⌨ เพื่อพิมพ์แทน

## การตรวจจับภาษา

เบราว์เซอร์ไม่มี "auto-detect" ภาษาพูดจริงๆ ในตัว (ต้องบอกภาษาก่อนเริ่มฟังเสมอ) แอปจึงแก้ปัญหานี้ด้วย
การเปิด **speech recognition สองตัวพร้อมกัน** ตัวหนึ่งฟังแบบตั้งสมมติภาษาที่ 1 อีกตัวฟังแบบตั้งสมมติภาษาที่ 2
ทั้งคู่ฟังเสียงเดียวกัน แล้วแอปเลือกฝั่งที่ถอดเสียงออกมาแล้ว "ตัวอักษรตรงกับภาษาที่ตั้งสมมติไว้เอง" เป็นผู้ชนะ
ถ้าฝั่งใดฝั่งหนึ่งไม่ได้ยินอะไรเลยหรือ error ก็เลือกอีกฝั่งโดยอัตโนมัติ

ใช้ได้ผลดีมากเมื่อสองภาษาที่ตั้งไว้ใช้ตัวอักษรคนละชุด (เช่น ไทย/อังกฤษ, จีน/อังกฤษ, ญี่ปุ่น/อังกฤษ)
เพราะเมื่อ engine ที่ตั้งภาษาผิดพยายามถอดเสียง มักได้ตัวอักษรชุดที่ไม่ตรงกับภาษาที่ตั้งไว้ แอปเลยรู้ว่าไม่ใช่คำตอบ

**ข้อจำกัดที่ควรรู้**: บางครั้ง engine ที่ตั้งภาษาผิดจะพยายาม "ทับศัพท์" เสียงเป็นตัวอักษรของภาษาที่ตั้งไว้แทน
(เช่น ได้ยินภาษาอังกฤษแต่ยัด engine ภาษาไทยให้ถอด ผลคือได้ตัวอักษรไทยเพี้ยนๆ แทนที่จะเป็นตัวอักษรอังกฤษ)
กรณีนี้แอปจะเข้าใจผิดว่าเดาถูก เพราะตรวจได้แค่ "ตัวอักษร" ไม่ได้ตรวจว่า "เนื้อหาถูกต้องจริงไหม" — เกิดขึ้นไม่บ่อย
แต่ถ้าเจอ แตะชื่อภาษาด้านบนเพื่อบังคับเทิร์นเองได้ทันที

คู่ภาษาที่ใช้ตัวอักษรชุดเดียวกัน (เช่น อังกฤษ/สเปน, ฝรั่งเศส/เยอรมัน) แยกด้วยตัวอักษรไม่ได้เลย
ต้องพึ่งการสลับเทิร์นตามลำดับจริง (แอปจำเทิร์นล่าสุดไว้ให้อัตโนมัติ) หรือแตะสลับเองเมื่อเดาผิด

## การใช้งาน

เปิด `index.html` ผ่าน **HTTPS** เท่านั้น — ไมโครโฟนของเบราว์เซอร์ต้องการหน้าเว็บที่ปลอดภัย
รองรับดีที่สุดบน Chrome (Android)

## เทคโนโลยีที่ใช้

- **Web Speech API** — รับเสียงพูดและอ่านออกเสียง (ในตัวเบราว์เซอร์)
- **[MyMemory API](https://mymemory.translated.net/)** — แปลภาษา ฟรี ไม่ต้องใช้ API key

## ⚠️ ข้อควรระวังเรื่องความเป็นส่วนตัว

ข้อความที่พูดหรือพิมพ์จะถูกส่งไปยังเซิร์ฟเวอร์ของ MyMemory ซึ่งเป็นคลังคำแปลสาธารณะ
ข้อความอาจถูกจัดเก็บและนำไปใช้ต่อได้

**อย่าใช้กับข้อมูลที่เป็นความลับ** เช่น รหัสผ่าน เลขบัตร ข้อมูลส่วนบุคคล หรือข้อมูลทางการแพทย์

นอกจากนี้ การรับเสียงพูดบน Chrome จะส่งเสียงไปประมวลผลที่เซิร์ฟเวอร์ของ Google
ตามกลไกของ Web Speech API

## โควตา

ตั้งค่า `CONTACT_EMAIL` ไว้แล้ว (อีเมลสำรองเฉพาะโปรเจกต์ ไม่ใช่อีเมลหลัก) จึงได้โควตา
**50,000 ตัวอักษรต่อวัน** — ถ้าอยากเปลี่ยนอีเมล แก้ค่าตัวแปรนี้ที่ต้นแท็ก `<script>` ใน `index.html`
(ไฟล์นี้เป็นสาธารณะ อีเมลที่ใส่จะถูกมองเห็นได้ อย่าใส่อีเมลหลัก)

MyMemory นับโควตาต่อ IP ของผู้ใช้แต่ละคน (แอปเรียก API จากเบราว์เซอร์ผู้ใช้โดยตรง)
ไม่ใช่โควตารวมของเจ้าของแอป

เมื่อโควตาหมด แอปจะแสดงข้อความ "โควตาวันนี้หมดแล้ว" พร้อมเวลาที่ใช้ได้อีกครั้ง
