# PARLEY — ล่ามพกพา

แอปแปลบทสนทนาสองทางแบบเรียลไทม์ หน้าจอเดียว ถือโดยเจ้าของเครื่องคนเดียว
ตั้งสองภาษาที่จะคุยไว้ครั้งเดียว แล้วแตะไมค์พูดสลับกันไปมาได้เลย
ไม่ต้องเลือกว่าใครพูดก่อน — แอปสลับภาษาที่คาดว่าจะฟังให้อัตโนมัติทุกครั้งที่แปลเสร็จ

- ไฟล์เดียวจบ ไม่ต้อง build ไม่ต้องติดตั้งอะไร
- รองรับ 36 ภาษา ตั้งคู่ภาษาแล้วสลับตำแหน่งได้ด้วยปุ่ม ⇄
- ถ้าเดาผิดว่าใครพูด แตะชื่อภาษาด้านบนเพื่อสลับเทิร์นเองได้ทันที
- ถ้าไมค์ใช้ไม่ได้ (เช่นบน iPhone/Safari) กดปุ่ม ⌨ เพื่อพิมพ์แทน

## การตรวจจับภาษา

เบราว์เซอร์ไม่มี "auto-detect" ภาษาพูดจริงๆ (ต้องบอกภาษาก่อนเริ่มฟังเสมอ) แอปจึงใช้ 2 ชั้น:

1. **สลับเทิร์นอัตโนมัติ** — เดาว่าใครพูดต่อจากคนที่เพิ่งได้ฟังคำแปลไป (ค่าเริ่มต้น)
2. **ตรวจตัวอักษรจากข้อความที่ถอดเสียงได้** — ถ้าคู่ภาษาที่ตั้งไว้ใช้ตัวอักษรคนละชุด
   (เช่น ไทย/อังกฤษ, จีน/อังกฤษ, ญี่ปุ่น/อังกฤษ) แอปจะจับได้เองว่าใครพูดจริง แม้เดาเทิร์นผิด

คู่ภาษาที่ใช้ตัวอักษรชุดเดียวกัน (เช่น อังกฤษ/สเปน, ฝรั่งเศส/เยอรมัน) แยกด้วยตัวอักษรไม่ได้
ต้องพึ่งการสลับเทิร์นตามลำดับจริง หรือแตะสลับเองเมื่อเดาผิด

## การใช้งาน

เปิด `index.html` ผ่าน **HTTPS** เท่านั้น — ไมโครโฟนของเบราว์เซอร์ต้องการหน้าเว็บที่ปลอดภัย
รองรับดีที่สุดบน Chrome (Android)

## เทคโนโลยีที่ใช้

- **Web Speech API** — รับเสียงพูดและอ่านออกเสียง (ในตัวเบราว์เซอร์)
- **[MyMemory API](https://mymemory.translated.net/)** — แปลภาษา ฟรี ไม่ต้องใช้ API key

## ⚠️ ข้อควรระวังเรื่องความเป็นส่วนตัว

ข้อความที่พูดหรือพิมพ์จะถูกส่งไปยังเซิร์ฟเวอร์ของ MyMemory ซึ่งเป็นคลังคำแปลสาธารณะ
ข้อความอาจถูกจัดเก็บและนำไปใช้ต่อได้

**อย่าใช้กับข้อมูลที่เป็นความลับ** เช่น รหัสผ่าน เลขบัตร ข้อมูลส่วนบุคคล หรือข้อมูลทางการแพทย์

นอกจากนี้ การรับเสียงพูดบน Chrome จะส่งเสียงไปประมวลผลที่เซิร์ฟเวอร์ของ Google
ตามกลไกของ Web Speech API

## โควตา

MyMemory แบบไม่ระบุตัวตนจำกัดราว 5,000 ตัวอักษรต่อวันต่อ IP
เนื่องจากแอปเรียก API จากเบราว์เซอร์ของผู้ใช้โดยตรง โควตาจึงนับแยกตามผู้ใช้แต่ละคน

เพิ่มเป็น 50,000 ตัวอักษรต่อวันได้ฟรี โดยใส่อีเมลในตัวแปร `CONTACT_EMAIL` ที่ต้นแท็ก
`<script>` ใน `index.html` — แต่ไฟล์นี้เป็นสาธารณะ อีเมลที่ใส่จะถูกมองเห็นและอาจโดนบอทเก็บไปสแปม
แนะนำให้ใช้อีเมลสำรอง

เมื่อโควตาหมด แอปจะแสดงข้อความ "โควตาวันนี้หมดแล้ว" พร้อมเวลาที่ใช้ได้อีกครั้ง
