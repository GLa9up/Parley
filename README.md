# PARLEY — ล่ามพกพา

แอปแปลบทสนทนาสองทางแบบเรียลไทม์ หน้าจอเดียว ถือโดยเจ้าของเครื่องคนเดียว
ตั้งสองภาษาที่จะคุยไว้ครั้งเดียว แตะชื่อภาษาด้านบนว่าใครจะพูด แล้วแตะไมค์พูดได้เลย

- ไฟล์เดียวจบ ไม่ต้อง build ไม่ต้องติดตั้งอะไร
- รองรับ 36 ภาษา ตั้งคู่ภาษาแล้วสลับตำแหน่งได้ด้วยปุ่ม ⇄
- แตะชื่อภาษาที่ปุ่มด้านบนก่อนพูด เพื่อบอกว่าใครจะพูดในเทิร์นนี้ — แปลเสร็จแต่ละครั้งแอปสลับให้อัตโนมัติ (คิดว่าอีกฝ่ายพูดต่อ) แก้ไขเองได้เสมอถ้าเดาผิด
- มีปุ่ม ↺ ล้างบทสนทนาทั้งหมด
- มีปุ่ม ⟳ รีเฟรชหน้าเว็บ พร้อมเช็คว่าเป็นเวอร์ชันล่าสุดหรือยัง
- เลขเวอร์ชันที่ใช้อยู่ (`APP_VERSION`) โชว์ตัวเล็กๆ ใต้ชื่อแอปเสมอ เทียบกับเวอร์ชันที่คุยกันไว้ได้ตรงๆ
- ถ้าไมค์ใช้ไม่ได้ (เช่นบน iPhone/Safari) กดปุ่ม ⌨ เพื่อพิมพ์แทน

## ทำไมไม่ auto-detect ภาษาที่พูด

เคยลองแล้ว — ให้ speech recognition สองตัวฟังพร้อมกันคนละภาษา แล้วเดาว่าฝั่งไหนถูกจากตัวอักษร
ที่ถอดออกมา ผลจริงคือ **ช้าลง** (ต้องรอสองเอนจินพร้อมกันทุกครั้ง) และ **เดาผิดได้ง่าย** เพราะเอนจินที่ตั้ง
ภาษาผิดมักไม่ถอดเสียงออกมาเป็นตัวอักษรที่ผิดชัดๆ ให้จับได้ แต่ทับศัพท์เป็นตัวอักษรของภาษาที่ตั้งไว้แทน
(เช่น ได้ยินอังกฤษแต่ engine ไทยถอดออกมาเป็นตัวอักษรไทยเพี้ยนๆ) ทำให้ตรวจตัวอักษรทีหลังก็ยังหลอกได้อยู่ดี

เว็บเบราว์เซอร์ไม่มี "auto-detect ภาษาพูด" ในตัวจริงๆ ต้องบอกภาษาก่อนเริ่มฟังเสมอ จึงตัดระบบเดาออก
ใช้วิธีตรงไปตรงมากว่า: **แตะชื่อภาษาด้านบนว่าใครจะพูด ก่อนแตะไมค์ทุกครั้ง** เร็วและแม่นยำกว่า
แอปยังสลับภาษาที่คาดว่าจะฟังให้อัตโนมัติหลังแปลเสร็จ (สมมติว่าอีกฝ่ายพูดต่อ) เพื่อลดจำนวนครั้งที่ต้องแตะ
แต่ถ้าคนเดิมพูดต่ออีกรอบ แตะชื่อภาษาแก้ก่อนพูดได้เสมอ ไม่ต้องรอให้แอปเดา

## การใช้งาน

เปิด `index.html` ผ่าน **HTTPS** เท่านั้น — ไมโครโฟนของเบราว์เซอร์ต้องการหน้าเว็บที่ปลอดภัย
รองรับดีที่สุดบน Chrome (Android)

## เทคโนโลยีที่ใช้

- **Web Speech API** — รับเสียงพูดและอ่านออกเสียง (ในตัวเบราว์เซอร์)
- **[MyMemory API](https://mymemory.translated.net/)** — แปลภาษา ฟรี ไม่ต้องใช้ API key

## ⚠️ ข้อควรระวังเรื่องความเป็นส่วนตัว

ข้อความที่พูดหรือพิมพ์จะถูกส่งไปยังเซิร์ฟเวอร์ของ MyMemory ซึ่งเป็นคลังคำแปลสาธารณะ
ข้อความอาจถูกจัดเก็บและนำไปใช้ต่อได้

**อย่าใช้กับข้อมูลที่เป็นความลับ** เช่น รหัสผ่าน เลขบัตร ข้อมูลส่วนบุคคล หรือข้อมูลทางการแพทย์

นอกจากนี้ การรับเสียงพูดบน Chrome จะส่งเสียงไปประมวลผลที่เซิร์ฟเวอร์ของ Google
ตามกลไกของ Web Speech API
