PARLEY

ดูที่ปุ่มไมค์ว่ากำลังจะฟังภาษาอะไร — ถ้าไม่ตรงกับคนที่จะพูด แตะชื่อภาษาที่ปุ่มด้านบนก่อน แล้วค่อยแตะไมค์พูด

แปลเสร็จแต่ละครั้ง แอปจะสลับภาษาที่จะฟังให้อัตโนมัติ (คิดว่าอีกฝ่ายจะพูดต่อ) ถ้าคนเดิมพูดต่ออีกรอบ แตะชื่อภาษาแก้ก่อนพูดได้เสมอ

ใช้ไมค์และลำโพงของเบราว์เซอร์ แปลผ่าน MyMemory API — ฟรี ไม่ต้องใช้คีย์

รองรับดีที่สุดบน Chrome (Android) — บน iPhone/Safari ถ้าไมค์ไม่ทำงาน ให้กดปุ่ม ⌨ เพื่อพิมพ์แทน
