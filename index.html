PARLEY

แตะไมค์แล้วพูดได้เลย ไม่ต้องสนใจว่าใครพูดก่อน — ระบบฟังสองภาษาที่ตั้งไว้พร้อมกันทุกครั้ง แล้วเลือกภาษาที่ตรงกับสิ่งที่พูดจริงให้เอง

ใช้ได้แม่นเมื่อสองภาษาที่ตั้งไว้ใช้ตัวอักษรต่างชุดกันชัดเจน (เช่น ไทย/อังกฤษ, จีน/อังกฤษ) — ถ้าใช้ตัวอักษรชุดเดียวกัน (เช่น อังกฤษ/สเปน) แยกไม่ออก ต้องพูดสลับกันตามลำดับ หรือแตะชื่อภาษาด้านบนเพื่อสลับเทิร์นเอง

ใช้ไมค์และลำโพงของเบราว์เซอร์ แปลผ่าน MyMemory API — ฟรี ไม่ต้องใช้คีย์

รองรับดีที่สุดบน Chrome (Android) — บน iPhone/Safari ถ้าไมค์ไม่ทำงาน ให้กดปุ่ม ⌨ เพื่อพิมพ์แทน
